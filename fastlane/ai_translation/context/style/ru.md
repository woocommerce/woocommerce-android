# Russian style notes

- Prefer concise phrasings; many existing human translations were verbose
  enough to break mobile UI elements.
- "Point of Sale" → keep as **"Point of Sale"** (the WooCommerce POS feature).
  Literal calques like "точка где выдаются товары" have caused confusion in
  past reviews; treat the term as a product name.
- Keep brand names (WooCommerce, Woo, WordPress.com, Jetpack) untranslated.
- Use informal register for app UI copy.
