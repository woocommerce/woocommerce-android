# AGENTS.md

This file provides guidance to AI Agents when working with code in this repository.

## Build Commands
- Build debug: `./gradlew assembleWasabiDebug`
- Install debug: `./gradlew installWasabiDebug`
- Run detekt: `./gradlew detektAll --auto-correct`

## Unit Test Commands
- Main app: `./gradlew :WooCommerce:testWasabiDebugUnitTest --tests "*.TestName"`
- CardReader: `./gradlew :libs:cardreader:testDebugUnitTest --tests "*.TestName"`
- Login: `./gradlew :libs:login:testDebugUnitTest --tests "*.TestName"`
- FluxC: `./gradlew :libs:fluxc:testDebugUnitTest --tests "*.TestName"`

## Architecture
- **MVVM** with Kotlin Coroutines and Hilt DI
- ViewModels extend `ScopedViewModel` (provides coroutine scope, `MultiLiveEvent` for one-shot events, `triggerEvent()`)
- UI uses Fragments hosting Compose via `ComposeView` with `DisposeOnViewTreeLifecycleDestroyed`
- Data layer uses FluxC (Room + network) with plugin-based architecture
- Navigation: XML nav graphs with NavController; Compose screens live inside Fragments
- DI modules in `WooCommerce/src/main/kotlin/com/woocommerce/android/di/`

## Main Modules
- **WooCommerce** - Main Android application
- **WooCommerce-Wear** - Wear OS companion app
- **libs/fluxc** - Core networking and data layer (includes fluxc-annotations, fluxc-processor, fluxc-plugin, fluxc-tests)
- **libs/cardreader** - Card reader functionality for payments
- **libs/login** - Authentication and login flows
- **libs/pos** - Point of sale functionality (POS)
- **libs/commons** - Shared Compose components, utilities, and test fixtures
- **libs/apifaker** - API mocking library for testing
- **libs/detektrules** - Custom detekt rules for this project

## Testing Patterns
- Extend `BaseUnitTest` (sets up `InstantTaskExecutorRule`, `CoroutineTestRule` with `UnconfinedTestDispatcher`)
- Use `testBlocking { }` helper (wraps `runTest`) for coroutine tests
- Naming: `` `given X, when Y, then Z` `` (backtick-wrapped, BDD style)
- Assertions: AssertJ (`assertThat(...).isEqualTo(...)`)
- Mocking: mockito-kotlin (`mock()`, `whenever()`, `verify()`)
- Compose tests: `ComposeTestRule` with finders/assertions/actions; use `waitUntil` not `Thread.sleep`

## Environment Setup
- Requires `secrets.properties` at `~/.configure/woocommerce-android/secrets/`
- Copy from `defaults.properties` and fill in OAuth2 credentials (see README)
- Java 21 (Amazon Corretto) required for remote build cache
- `local.properties` is auto-generated by Android Studio (contains SDK path)

## Key Rules
- Use Kotlin for all new code
- Use Jetpack Compose for new UI
- Standard detekt rules (see `config/detekt/detekt.yml` for customizations)
- Do not add comments to code (keep existing comments if present)
- Max line length: 120 characters
- No wildcard imports
- Do not acquire ViewModels inside composables; inject as parameter with default value
- Composables: always accept `Modifier` as first optional parameter
- Use state hoisting in Compose (state up, events down)

## Commit Guidelines
- Never use "Co-Authored-By" in commit messages
- Never mention that code was generated by AI/Claude
- Keep commit messages under 100 characters
- Focus on what was done, not implementation details
